BIS Concrete Mix Recommendation System
An ML-powered decision support system for BIS-oriented concrete mix recommendation using machine learning, explainability, and engineering validation.

Features
Concrete strength prediction
CatBoost, XGBoost, Random Forest, LightGBM models
Hyperparameter tuning
SHAP explainability
BIS-based mix recommendation
Streamlit web application
